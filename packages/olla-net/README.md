# olla-net

This package holds the hyphenated name **`olla-net`** so it cannot be registered by someone else.

The real CLI is **[ollanet](https://www.npmjs.com/package/ollanet)**:

```bash
npm install -g ollanet
ollanet scan
```

We intentionally do **not** claim names that embed the full “Ollama” trademark (for example `ollamanet`).
